📝 Personal Task Tracker
This is a small personal project I’m building to track my daily tasks and stay organized. It’s not meant to be anything fancy—just a simple tool to help me stay on top of what needs to get done. I'm using this as a learning opportunity and also getting a bit of help from ChatGPT along the way to speed things up.

The goal is to keep the project lightweight and functional, with just the features I actually need. Think of it as a digital notepad, but a bit smarter.

More features may come if I feel the need, but for now, it’s a fun and focused side project.
