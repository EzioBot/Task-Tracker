# Personal Task Tracker

A lightweight PyQt5 task tracker for keeping daily work organized.

## Features

- Mobile-sized task dashboard
- Add and edit tasks from one details dialog
- Due dates, timer-based reminders, priority, notes, and completion status
- Search plus All, Active, Today, Late, and Done filters
- Local JSON persistence in `tasks.json`

## Install

```bash
pip install PyQt5
```

## Run

```bash
python main.py
```
